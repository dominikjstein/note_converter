# 📝 Markdown Link Converter – Obsidian ↔ Notion

## 🇩🇪 Deutsch

### 🔄 Was ist das?

Ein moderner Markdown-Link-Konverter für Windows. Er ermöglicht die einfache Umwandlung von Markdown-Dateien zwischen dem **Obsidian-Link-Format** (`[[Seitenname]]`) und dem **Notion-kompatiblen Markdown-Link-Format** (`[Seitenname](Seitenname.md)`).

> ✅ **Keine Python-Installation notwendig!**  
> Die App wurde bereits als `.exe` kompiliert – einfach herunterladen und starten.

---

### 🎯 Funktionen

- Einfache grafische Oberfläche (GUI)
- Ordnerauswahl mit rekursiver Verarbeitung aller `.md`-Dateien
- Zwei Konvertierungsmodi:
  - `[[Seite]]` → `[Seite](Seite.md)` (Obsidian → Notion)
  - `[Text](Seite.md)` → `[[Seite|Text]]` (Notion → Obsidian)
- Automatische Backups: Jede Datei wird vor der Bearbeitung als `.bak` gesichert

---

### 🖥️ Nutzung

1. `.exe` herunterladen (siehe [Releases](https://github.com/DEIN-USERNAME/REPO-NAME/releases))
2. Doppelklick – die App startet
3. Ordner auswählen → Richtung wählen → Start drücken ✔️

---

### 🔐 Sicherheit

- Es werden keine Daten übertragen
- Jede Datei wird **lokal verarbeitet**
- Automatisches **Backup** der Originaldateien (`.bak`)

## 🇬🇧 English

### 🔄 What is this?

A modern Markdown link converter for Windows. It allows easy conversion of Markdown files between the **Obsidian link format** (`[[Page Name]]`) and the **Notion-compatible Markdown link format** (`[Page Name](Page Name.md)`).

> ✅ **No Python installation required!**  
> The app is already compiled as a `.exe` – just download and run.

---

### 🎯 Features

- Simple and modern GUI
- Folder selection with recursive `.md` file processing
- Two conversion modes:
  - `[[Page]]` → `[Page](Page.md)` (Obsidian → Notion)
  - `[Text](Page.md)` → `[[Page|Text]]` (Notion → Obsidian)
- Automatic backups: Each file is saved as `.bak` before being modified

---

### 🖥️ How to Use

1. Download the `.exe` file (see [Releases](https://github.com/YOUR-USERNAME/REPO-NAME/releases))
2. Double-click to start the app
3. Select folder → Choose conversion direction → Hit start ✔️

---

### 🔐 Security

- No data is sent anywhere
- All files are processed **locally**
- Automatic **.bak** backups of original files
